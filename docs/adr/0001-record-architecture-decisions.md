# 1. Record architecture decisions

- Status: accepted
- Date: 2026-11-07

## Context

Design choices made today need to stay understandable to future contributors, including AI agents that start each session without history.

## Decision

Record each significant decision as a numbered file in `docs/adr/`, using the format of this file: context, decision, and consequences. Decisions are never edited after acceptance. A new record replaces an old one and links back to it.

## Consequences

Contributors can see why the project is shaped the way it is. Reversing a decision takes a new record, which makes changes deliberate.
